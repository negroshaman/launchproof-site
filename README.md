# LaunchProof site

Lean Phase 0 website for LaunchProof, a software-engineer-led Shopify Store Journey Audit.

## Positioning guardrails

- Product discovery through cart and checkout entry
- Safe-stop before purchase or payment
- Desktop and mobile journey coverage
- Developer-ready findings based on observed evidence
- 48–72 hour delivery after scope, access and context are ready
- No invented clients, results, testimonials, logos or revenue claims
- No agency-scale or conversion-guarantee claims

## Hosting

The site is intentionally dependency-free and works directly on GitHub Pages. It is currently marked `noindex, nofollow` until public search indexing is approved.

## Local preview

Serve the repository root with any static file server, then open `index.html` through the local URL.
